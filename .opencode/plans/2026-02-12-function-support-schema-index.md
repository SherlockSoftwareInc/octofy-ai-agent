> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Enable the Schema Index-Based Search Feature to discover, index, score, and surface SQL Functions alongside Tables and Views.

**Architecture:** Functions are added as a first-class object type throughout the offline index generation pipeline, the runtime two-stage scoring engine, and the REST API. The existing `object_discovery_service.py` already discovers functions from SQL Server and generates Markdown for them -- this plan wires that capability into the index pipeline and boosts function discoverability with a 1.2x scoring multiplier.

**Tech Stack:** Python 3.8+, FastAPI, JSON index files, regex-based Markdown parsing.

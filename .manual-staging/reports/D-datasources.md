## Cross-cutting notes for the parent

1. **MariaDB is not selectable.** `ConnectionType` has a `MariaDB` member (`DatabaseConnectionItem.cs:274`) and the MySQL schema provider serves MariaDB, but the provider combo has no MariaDB entry (`ConnectionManageForm.cs:211-230`, `NewSQLServerConnectionDialog.cs:204-223`), and `GetActiveNativeEditor` falls back to the SQL Server editor for it (`ConnectionManageForm.cs:37-46`). MariaDB only appears when a legacy saved record is recovered (`SQLServerConnections.cs:432-449`). The pages therefore document MariaDB servers under **MySQL connection** and say MariaDB is not a separate list entry. If the product intends a separate MariaDB picker, that is a product gap, not a doc gap.
2. **The plan's intended UI was not fully delivered.** `NATIVE_DBMS_MULTIPROVIDER_PLAN.md` §2.6/§8.3 (lines 481-531, 1241-1252) specifies a six-member combo including MariaDB, a `Port` field, per-provider Schema/SearchPath, SSL-mode and connect-timeout fields, an ODBC DBMS hint, and a dedicated `StandardCredentialLoginDialog` with its own labels. The shipped code has none of these controls (native boxes subclass `SQLConnectionBox`; `ODBCConnectionBox.resx` has no hint combo; `StandardCredentialLoginDialog` reuses the SQL Server dialog, `:12-22`). The OctofyPro draft pages under `OctofyPro\Docs\User Manual\` describe the *planned* Port/SSL/Connect-timeout fields; those were **not** copied — the pages document the delivered UI only.
3. **No SQLite support found**: no provider, connection box, enum member, or package reference for SQLite anywhere in the solution; not documented. MongoDB/Redis/Elasticsearch/Cassandra/DB2 exist only as unused `DBMSTypeEnums` values; ODBC remains the fallback for DB2/Excel/Access/generic sources (plan §8.4).
4. **Stale developer doc.** `database-connection-summary.md` is dated 2026-09-19 but §3.1 still shows `{ SQLServer, ODBC }`, §4.2 still describes the Add dialog as SQL-Server/ODBC-only, §5.5 still routes all non-SQL-Server traffic to ODBC, and §9.2 still claims the default auth branch overrides `TrustServerCertificate` (the release notes say the opposite, `:22-24`). I followed the code and the Stage 6 release notes wherever they conflict.
5. **Encoding.** Live `add-data-source.md` and `browser-the-database.md` are cp1252 (0x97 em dashes), the other manual pages are mixed UTF-8/CRLF/LF. The new files are UTF-8 (no BOM) and keep each original's CRLF line endings and trailing blank line; `## Screenshots` segments compare byte-identical to the baseline.
6. **Inert UI found but not documented** (no user-visible effect): the Object Browser's **Edit > Copy** item has no click handler (`ObjectBrowserForm.Designer.cs:253-256`); `excelFileAnalysisToolStripMenuItem.Text` ("Excel file analysis") exists in `ObjectBrowserForm.resx` with no menu wiring; `DBObjectTree`'s **Build SELECT script** handlers exist (`DBObjectTree.Designer.cs:121`) but its enable/disable lines are commented out (`DBObjectTree.cs:555,566,577,591,602,613`) so it stays enabled for every node — documented as a plain menu entry only.
7. **Native status-bar gap** (also noted under change-data-source): non-SQL Server connections render `connection.DSN`, which is empty for native items, so the server/database labels stay blank for PostgreSQL/MySQL/Oracle in both windows (`ObjectBrowserForm.cs:524-528`, `AdvancedQueryAnalysisForm.cs:1500-1504`). Candidate product bug.

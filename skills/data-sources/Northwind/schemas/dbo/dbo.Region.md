# Table: [dbo].[Region]

**Data Source:** Northwind
**Schema:** dbo
**Type:** Table

## Description

# **Table:** `[dbo].[Region]`
> Contains information about geographical regions used for organizing sales territories or shipping areas.
---
### **Columns:**
| Ord | Name | Data Type | Description |
|:---:|:---:|:---:|:---|
| 1 | `RegionID` | INTEGER | Primary key, Unique identifier for the region. |
| 2 | `RegionDescription` | NCHAR(50) | Descriptive name or label for the region. |
---

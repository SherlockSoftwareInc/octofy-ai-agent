## Description

The NORTHWIND database supports day-to-day order processing and inventory management for a wholesale trading company, capturing sales transactions, customers, suppliers, employees, and shippers. It also provides a foundation for SQL-based analytics through pre-built views that summarize sales performance by product, category, and time

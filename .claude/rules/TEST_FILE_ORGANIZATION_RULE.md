# Test File Organization Rule (Claude Code)

All test files for Claude code must be placed in the `tests/` folder. Do not place test files in the root or other directories. Name test files as `test_*.py` and ensure they reside in `tests/`.

**Rule:**

- All files matching `test_*.py` must be in the `tests/` directory.

**Example:**

- Correct: `tests/test_skills_search.py`
- Incorrect: `test_skills_search.py` (in project root)
